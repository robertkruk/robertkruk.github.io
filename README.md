# Robert Kruk's Blog

Personal blog built with Jekyll and the [Chirpy][chirpy] theme, hosted on GitHub Pages.

## About

This blog covers topics including:
- AWS and cloud architecture
- DevOps and infrastructure automation
- Database technologies and security
- Software engineering best practices

## Visit the Blog

**[robertkruk.github.io](https://robertkruk.github.io)**

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

## Theme Documentation

For theme customization and features, check out the [Chirpy theme docs](https://github.com/cotes2020/jekyll-theme-chirpy/wiki).
