# Welcome to My New Site!

This is my first post using the **Chirpy** Jekyll theme. Here are some of the amazing features:

## Features

- 🌓 **Dark/Light Mode Toggle** - Switch themes with one click
- 🔍 **Built-in Search** - Find content quickly
- 📱 **Responsive Design** - Looks great on all devices
- 🏷️ **Categories & Tags** - Organize your content
- 📖 **Table of Contents** - Navigate long posts easily

## Code Highlighting

Chirpy has excellent syntax highlighting:

```python
def hello_world():
    print("Hello from my new Chirpy site!")
    return "Welcome!"

hello_world()
```
